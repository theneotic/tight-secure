# Password Atlas — Design Exploration

## Three possible directions

### Theme Name: Petal Instrument Panel
**Very Brief Intro:** A tactile security instrument built from porcelain surfaces, frosted glass, and a softly floral pastel atmosphere. It makes password education feel calm rather than alarming.

**Probability:** 0.07

### Theme Name: Midnight Signal
**Very Brief Intro:** A nocturnal security console built around inky fields, electric status lights, and laser-fine information marks. It emphasizes urgency and technical precision.

**Probability:** 0.04

### Theme Name: Library Cipher
**Very Brief Intro:** A warm editorial workspace inspired by bound field journals, marginalia, and archival diagrams. It frames password choices as thoughtful, private record-keeping.

**Probability:** 0.09

## Chosen approach: Petal Instrument Panel

### Design Movement
Soft skeuomorphism crossed with contemporary glassmorphism and **pastel editorial photography**. The interface uses the supplied floral, coastal blue, pink, and lilac cue as a calming counterweight to a normally intimidating security topic.

### Core Principles
1. **Tactile clarity:** Controls should suggest physical pressability and measured depth without becoming ornamental clutter.
2. **Calm expertise:** Risk feedback should be clear, contextual, and specific without shame or panic language.
3. **Layered transparency:** Frosted panes provide structure while the pastel atmosphere remains visible beneath.
4. **Useful visual evidence:** Every chart and indicator must explain a security decision, not decorate empty space.

### Color Philosophy
The base is pearl and fog, which creates a clean, non-technical environment. Powder blue carries trust and analytical focus; blush pink introduces warmth; dusty indigo adds dependable contrast; the selected accent palette can individualize the interface without changing its quiet character. Dark mode moves to a plum-charcoal field with translucent cool-grey panels so the atmosphere remains soft rather than neon.

### Layout Paradigm
The home screen behaves like an **instrument tray** rather than a centered marketing page. A large left analysis tray occupies the primary field, while stacked assessment, contextual-risk, and learning modules create an asymmetrical right column. On small screens, the tray unfolds into an ordered single-column reading path.

### Signature Elements
1. An inset, concave password field with a glowing status bead.
2. Rounded translucent “lens” cards that combine a frosted rim, subtle inner highlight, and soft cast shadow.
3. A thin flowering-grid pattern that appears at the edges of panels and in the hero atmosphere.

### Interaction Philosophy
Every password edit updates the assessment immediately and privately in the browser. Selection controls respond like carefully made physical switches, while educational guidance expands from the result rather than interrupting it. Palette and light/dark controls feel like adjusting a personal desk lamp.

### Animation
Panels rise only 6px with opacity when the page arrives, in a short stagger. Strength rings and metric bars transition with a decisive ease-out when values change. Buttons depress on activation, and palette dots swell slightly on hover. All nonessential animation is disabled for reduced-motion preferences.

### Typography System
**DM Serif Display** creates a composed, editorial title voice. **Manrope** carries instructional prose, controls, and quantitative labels for compact readability. Titles use strong asymmetric scale; metadata uses small tracked uppercase labels; numbers receive a slightly heavier Manrope weight.

### Brand Essence
**Password Atlas is a calm visual field guide for people who want to make password decisions that match what they are protecting.**

Personality: **reassuring, precise, observant**.

### Brand Voice
Headlines are direct and quietly confident; CTAs are practical and specific; microcopy treats the visitor as capable.

Example lines: “Read the signals before you reuse a secret.”

Example lines: “This login protects more than a profile — choose accordingly.”

### Wordmark & Logo
The logo is a compact compass-keyhole mark: four quiet directional points converge into a secure keyhole, suggesting both orientation and protection. The wordmark uses a high-contrast editorial serif with a fine sans-serif descriptor.

### Signature Brand Color
**Petal Blue — #7DA7D8.**

## Style Decisions

- Dark text is mandatory over the light hero imagery and pastel surfaces.
- Security advice avoids exaggerated claims and explains why a factor changes risk.
- The default interface is light, with dark mode treated as an equally designed state.
- The ten accent options translate the supplied colour-system reference into a personal but consistent dashboard treatment.
- The flowering-grid motif now repeats across analysis and context-panel edges so the instrument system is identifiable beyond the hero.
- Petal Blue (#7DA7D8) is the default signal colour, leading the main score, selected states, and primary action before users choose a personal accent.
- The compass-keyhole mark now has a dedicated tactile seal treatment to give the compact identity stronger presence.
